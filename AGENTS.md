## Agent skills

### Issue tracker

Tasks live under `.scratch/<feature>/issues/`; shared specs live in `docs/specs/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `ready-for-refinement`, `in-refinement`, `ready-to-implement`, `in-progress`, `in-review`, `done`, `cancelled`; independent `blocked` marker. See `docs/agents/triage-labels.md`.

### Domain docs

Repository context: `CONTEXT.md`; product briefs: `docs/product/`; decisions: `docs/adr/`; domain glossary: `docs/domain/glossary.md`. See `docs/agents/domain.md`.
