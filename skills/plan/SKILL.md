# Plan

Read the selected tasks, relevant code and [artifact contract](../project-setup/references/artifacts.md). Analyst may facilitate; Architect may supply technical recommendations. This is optional: Lead can plan during autonomous implementation intake.

Preserve task identities and accepted behavior. Synthesize accepted requirements without restarting the interview. Identify existing public interfaces/test seams that can verify the outcomes, reusing the highest useful behavior boundary; justify new seams only when necessary. Add a proportionate implementation sequence, affected boundaries, checks and dependency graph to the existing task or linked technical document. Do not generate a second set of implementation tickets by default. If the scope needs separate independently deliverable tasks, propose Slice and refinement for them.

Inspect code to answer technical questions. Route new consequential product gaps to Analyst/user and return affected tasks to refinement within authorized scope. Persist through configured tools, preserving unrelated fields; report links and unresolved blockers. Do not start execution automatically.
