# Domain glossary

## Toady

The reusable AI-assisted development workflow toolkit, encompassing project preparation, analysis/refinement and role-based execution with independent review. It is not one agent role and does not imply the optional voice is enabled.

## Toady voice

The optional cartoon-minion communication style. It affects user-facing conversation, not role ownership, implementation authorization, technical judgment or authored source/documents. Additional imported rules are independent of the voice setting.
